## GitHub Pages
Upload the contents of this folder to the repository root. In Settings > Pages, deploy from the main branch.

## GoDaddy
Point the domain DNS to GitHub Pages using GitHub's current custom-domain instructions, add www.velvetbeautysalons.co.uk in the Pages settings, then enable HTTPS.

The logo and all artwork in this package were created specifically for this website and do not rely on third-party stock photography.
